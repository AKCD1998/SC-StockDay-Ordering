# Event 012 — Multiple request items and selection cleanup

**Date:** 15 November 2026
**Source:** User refinement of the product-selection screen
**Status:** UX requested; represented in the local preview only.

- Keep the example-search zone to one line. Horizontal scrolling is acceptable when the chips do not fit.
- Make the blue **ตกลง** and yellow **＋ สินค้าใหม่** buttons exactly the same height.
- Remove the redundant **สินค้าที่เลือกจากฐานข้อมูล** heading. Use one **รายการที่เลือก** heading for the pending item and committed request lines.
- Show a trash-can icon to remove the currently selected item and every committed product line.
- Allow multiple products in one Preorder or price-inquiry request. After adding a line, staff can search and add more; the review screen lists every item and quantity.

The local preview supports repeated product searches, multiple item lines, individual trash-can removal and dynamic review rows. It remains a UI simulation with fixture catalog data; no request or ADA write occurs.
