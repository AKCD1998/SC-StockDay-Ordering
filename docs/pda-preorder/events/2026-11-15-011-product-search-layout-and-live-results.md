# Event 011 — Product search layout and live results

**Date:** 15 November 2026
**Source:** User refinement of the SCPDA product picker
**Status:** UX requested; represented in the local preview only.

## Search controls

- Put the barcode icon button at the right edge inside the **สินค้า / บาร์โค้ด** input. Use a high-contrast fill and a distinct tap target.
- Typing should show dynamic catalog matches. **ตกลง** opens the full result picker, where typing can continue to filter the list.
- Put blue **ตกลง** and yellow **＋ สินค้าใหม่** side by side in two equal columns, using the SC company colors.
- Show example queries that can be tried: Thai **สินค้า A**, English **Product B**, company code **IC-002**, legacy code **630003**, and a sample barcode.
- Catalog results use Thai display names; long names wrap and each row grows to fit.

Event 011 supersedes event 010's instruction to place barcode scanning on a separate full-width row. The product lookup and new-item flow in event 010 otherwise remains.

The updated local mock provides example products A/B/C and filters by Thai/English names, aliases, IC code, legacy code and barcode. It does not query ADA Software; its product records and matching data remain synthetic.
